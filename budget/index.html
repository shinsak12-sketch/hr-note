대분류 · 중분류 · 소분류(선택)와 순번, 더존 과목 연결을 관리합니다.

분류
계획 칸 클릭 = 산출 입력 · 월 · 비고 칸 = 바로 입력 (숫자 치기 · 더블클릭 · F2, Enter/Tab/방향키로 이동, Delete 지우기) · 열 우클릭 = 정렬 · 필터 · 틀 고정 · 일괄 적용
Ctrl/Shift + 클릭 = 여러 계정 선택 · ⋮⋮ 끌기 = 순서 바꾸기 (같은 상위 안) · 리본 묶음 오른쪽 ⋮⋮ 끌기 = 묶음 위치 바꾸기 · Ctrl+Z / Ctrl+Y = 실행 취소 / 다시 실행 (최근 100번) · Ctrl+F = 계정 검색
계정 분류 · 순번 · 더존 과목 연결은 설정 › 분류 관리에서 바꿉니다. 소분류가 없으면 중분류가, 있으면 소분류가 계정입니다. 저장할 때마다 버전이 남습니다.
계획 마감 후에는 계획을 고칠 수 없고, 금액 있는 계정은 옮기거나 지울 수 없습니다. 고치려면 계획 변경(1차 · 2차 …)을 열고, 끝나면 변경 마감. 마감 뒤에 생긴 계정은 계획 외입니다.
금액은 항상 원 단위로 입력합니다. 표시 단위는 보기용입니다. 월별 금액은 반올림 단위로 맞추고, 확정 계획액 = 월별 금액의 합입니다.
바뀔 때마다 data\사업비계획_연도.xlsx에 자동 저장되고, 이전 파일은 backup 폴더에 30분마다 보관됩니다(연도별 최근 30개).
