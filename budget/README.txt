사업비 관리 프로그램 — 사업비 계획 (테스트판)
==============================================

■ 실행
  1) 압축을 풀기 전에: zip 우클릭 → 속성 → [차단 해제] 체크 (있을 때만)
  2) 원하는 곳에 압축 풀기 (예: 바탕화면\budget)
  3) budget 폴더의 index.html 을 크롬(또는 엣지)으로 열기
     - 설치 · 서버 · 인터넷 필요 없음

■ 처음 한 번
  1) [폴더 연결] → index.html 이 들어 있는 budget 폴더를 고르기 → [파일 수정 허용]
     (크롬이 다시 묻지 않게 하려면 [방문할 때마다 허용])
  2) [샘플 데이터로 시작] 으로 둘러보거나 [새 연도 만들기]

■ 분류 (계정) 관리 — 리본 [설정] › [분류 관리]
  - 대분류 · 중분류 · 소분류를 3단 목록에서 추가 · 이름 수정 · 삭제
  - 순서(순번): ⋮⋮ 를 끌거나 번호 칸의 숫자를 고치고 Enter
  - 소분류를 다른 중분류 위로 끌면 옮겨지고, 중분류를 다른 대분류 위로 끌어도 옮겨짐
  - 소분류의 [사용] 을 끄면 계획 표에서 숨김 (입력값은 보관)
  - ERP코드: 전년 실적 가져오기 때 먼저 맞춰 보는 코드 (비워도 됨 — 그때는 계정명으로 맞춤)
  - 분류는 모든 연도가 같이 씀: budget\data\기준정보.xlsx
  - 계획 표에서도 같은 중분류 안의 계정 줄은 ⋮⋮ 를 끌어 순서를 바꿀 수 있음
  - [계정 추가]: 대·중·소분류를 목록에서 고르거나 직접 입력. 새 분류면 "신설할까요?" 를 묻고 만듦

■ 저장
  - 바뀔 때마다 자동 저장:  budget\data\사업비계획_2027.xlsx  (분류는 budget\data\기준정보.xlsx)
  - 이전 파일 자동 보관:    budget\backup\사업비계획_2027_날짜_시각.xlsx  (30분마다, 연도별 최근 30개)
  - data 의 엑셀 파일은 그냥 엑셀로 열어 봐도 됩니다.
    단, 프로그램이 저장하는 동안 엑셀로 열어 두면 저장이 실패합니다 → 엑셀을 닫고 제목 줄의 빨간 표시를 누르면 다시 저장.

■ 사용법
  - 계정 줄 클릭 = 선택 / 더블클릭 · Enter · 계획액 칸 클릭 = 산출 입력 팝업
  - ↑↓ 줄 이동, Ctrl+Z 실행 취소, Ctrl+Y 다시 실행, Ctrl+F 계정 검색, Delete 계정 삭제
  - 금액은 원 단위로 입력. 표시 단위(원/천원/백만원/억원)는 보기용
  - 월별 금액은 반올림 단위·방식으로 맞추고, 확정 계획액 = 월별 금액의 합
  - [전년 실적 가져오기]: ERP 엑셀을 고르면 코드 · 계정명 · 금액 열을 찾아 계정별로 합산해서 넣음
  - [보고용 엑셀]: 소계·합계가 들어간 보고용 파일을 내려받기

■ 다음 단계에서 만들 화면
  실적 입력, 계획 대비 실적, 수입 관리, 대시보드 (아래 시트 탭에 '준비 중'으로 표시)
