사업비 관리 프로그램 — 사업비 계획 · 집행 (테스트판)
==============================================

■ 실행
  1) 압축을 풀기 전에: zip 우클릭 → 속성 → [차단 해제] 체크 (있을 때만)
  2) 원하는 곳에 압축 풀기 (예: 바탕화면\budget)
  3) budget 폴더의 index.html 을 크롬(또는 엣지)으로 열기
     - 설치 · 서버 · 인터넷 필요 없음

■ 처음 한 번
  1) [폴더 연결] → index.html 이 들어 있는 budget 폴더를 고르기 → [파일 수정 허용]
     (크롬이 다시 묻지 않게 하려면 [방문할 때마다 허용])
  2) [새 연도 만들기] 또는 [2026년 테스트 데이터로 시작]
     - 테스트 데이터(가짜 금액): 2026년 계획(원안 마감 + 1차 변경 마감)
       + 더존원본\2026\분개장_08월.xls · 손익_08월.xls · 분개장_09월.xls · 손익_09월.xls (집행 테스트용)
       + 더존원본\2026_손익_1-12월_테스트.xls ([전년 실적 가져오기] 테스트용)
     - 해 볼 순서: [집행] 탭 → [더존 자료 읽기] (8월 · 9월 파일이 같이 읽힘. 9월 자료에서 7월이 바뀐 것 2건이 '지난 달 수정'으로 잡힘)
       → [새 연도 만들기] 2027 → '2026년 실적으로 시작'
     - 파일 탭 [2026 테스트 데이터] 로 언제든 다시 만들 수 있음

■ 새 연도 만들기 — 리본 [파일]
  - 'YYYY년 실적으로 시작 (추천)': 전년 집행(더존 분개장)을 전년 실적 · 월별로 넣음. 작년 계획이 아니라 작년 실적을 가져옴
    · 집행이 12월까지 안 됐으면: 연말 예상 = 집행한 달 + 남은 달은 작년 최종 계획 / 또는 집행 있는 달만
    · 산출 방식은 비워 두고 새로 잡음. 계획 칸 팝업 아래에 작년 집행 메모가 같이 보임
  - '빈 계획으로 시작': 분류만 쓰고 비움. 전년 실적은 [전년 실적 가져오기](더존 손익 출력, 판관비 부분만 읽음)로 넣음

■ 분류 (계정) 관리 — 리본 [설정] › [분류 관리]
  - 처음에는 기본 분류가 들어 있음: 내부 자료 작성용 서식의 대분류 26 · 중분류 93 + 더존 과목 95 (계정코드 포함)
  - 대분류 › 중분류 가 기본. 소분류는 선택 — 소분류가 없으면 중분류가 계정, 있으면 소분류가 계정
  - 4칸 화면: 대분류 | 중분류 | 소분류 | 더존 과목 연결
  - 더존 과목은 계정(가장 아래 칸)에 연결. 한 계정에 여러 과목 가능 (예: 직원급여 ← 직원급여 + 성과급 + 성과가급)
    · 코드나 이름 하나만 넣어도 더존 계정과목표(판매관리비)에서 나머지를 채움
    · 이미 다른 칸에 연결된 과목이면 이쪽으로 옮길지 물음
  - [＋ 소분류 추가]: 중분류를 처음 나누면 연결된 더존 과목과 계획 입력값이 첫 소분류로 옮겨짐 (다른 소분류로는 [옮기기])
  - 순서(순번): ⋮⋮ 를 끌거나 번호 칸의 숫자를 고치고 Enter. 다른 상위 위로 끌면 옮겨짐
  - [사용] 을 끄면 계획 표에서 숨김 (입력값 · 더존 연결은 보관)
  - [양식 다운]: 지금 분류를 엑셀로 (한 줄 = 더존 과목 하나). 엑셀에서 고친 뒤 [양식 업로드]
    → 바뀌는 내용을 먼저 보여주고 [적용] → [저장] 해야 반영됨
  - [버전 이력]: 저장할 때마다 v1, v2 … 로 기록. 버전별 바뀐 것 · 전체 분류표 · 양식 다운
    되돌리기는 없음. [이 버전 복사해서 편집] 은 그때 분류표를 불러올 뿐이고 [저장]해야 새 버전이 됨
  - 분류는 모든 연도가 같이 씀: budget\data\기준정보.xlsx (분류 · 버전 · 버전내용 시트)
  - 계획 표에서도 같은 상위 안의 계정 줄은 ⋮⋮ 를 끌어 순서를 바꿀 수 있음. 대분류 줄도 ⋮⋮ 를 끌어 대분류끼리 순서 변경
  - [계정 추가]: 대 · 중 · 소분류(선택)를 고르거나 직접 입력. 새 분류면 "신설할까요?" 를 묻고 만듦

■ 계획 마감 · 변경 — 리본 [계획] › 확정
  - [계획 마감]: 먼저 검증 화면(입력 필요 · 비율 합 · 산출과 다른 월 금액 · 큰 변동 · 신규 · 더존 연결 없음)을 보고,
    항목을 누르면 그 계정으로 이동. 확인 체크 후 원안으로 확정. 이후 계획 금액 · 산출 방식 · 전년 실적 · 반올림 설정을 바꿀 수 없음
    금액 있는 계정은 분류에서 옮기기 · 삭제 · 사용 안 함 불가 (🔒 표시)
  - [계획 변경]: 전체를 열어 1차 · 2차 … 변경 시작 (사유는 선택). 표에 '변경 전' 열과 '변경' 표시
    → [변경 마감] 으로 확정, [변경 취소] 로 직전 마감 상태로 되돌림
  - [변경 기록]: 원안 · 차수별 합계와 바뀐 계정. 계획 대비 실적은 마지막 마감본(최종 변경안) 기준
  - 마감 뒤에 새로 만든 계정은 '계획 외' — 계획 없이 실적만 들어가는 연중 예외 항목
  - 연도 파일의 '차수' · '마감본' 시트에 마감할 때의 계획이 그대로 남음

■ 저장
  - 제목 줄의 작은 캐릭터: 저장 중엔 바쁘게 움직이고, 저장에 실패하면 고개를 흔듭니다
  - 바뀔 때마다 자동 저장:  budget\data\사업비계획_2027.xlsx  (분류는 budget\data\기준정보.xlsx)
  - 이전 파일 자동 보관:    budget\backup\사업비계획_2027_날짜_시각.xlsx  (30분마다, 연도별 최근 30개)
  - data 의 엑셀 파일은 그냥 엑셀로 열어 봐도 됩니다.
    단, 프로그램이 저장하는 동안 엑셀로 열어 두면 저장이 실패합니다 → 엑셀을 닫고 제목 줄의 빨간 표시를 누르면 다시 저장.

■ 사용법
  - 계획 칸 클릭(또는 Enter) = 산출 입력 팝업
  - 1~12월 칸 · 비고 칸 = 엑셀처럼 바로 입력
    · 칸을 누르고 바로 치기(한글도 됨) · 더블클릭 · F2 = 고치기 / Enter · Tab · 방향키 = 저장하고 이동 / Esc = 취소 / Delete = 지우기
    · 월 금액을 직접 고치면 그 계정은 '수기' 분할이 되고 확정 계획액 = 월 합계 (산출 금액과 다르면 '산출 대비' 표시)
  - 탐색바: 계정 검색(글자) + 대분류 › 중분류 › 소분류 드롭다운 + [확인 필요] 버튼
  - 열 머리(또는 칸) 우클릭 = 정렬 · 필터 · 틀 고정 · 일괄 적용. 도구 줄 [모두 해제]로 한 번에 풀기
  - Ctrl + 클릭 = 여러 계정 선택, Shift + 클릭 = 범위 선택, 대분류 줄 우클릭 = 그 대분류 모두 선택
  - [일괄 적용]: 선택한 계정 / 보이는 계정 / 대분류에 %증감 · 절대증감 · 균등 · 작년처럼 · 메모를 한 번에
  - 금액은 원 단위로 입력. 입력칸 옆에 한글 금액(예: 일천만원)이 보임. 표시 단위(원/천원/백만원/억원)는 보기용
  - 월 분할: 연간 금액을 반올림 단위·방식으로 먼저 확정한 뒤 달로 나눔. 나눠 떨어지지 않는 끝수는
    균등 = 12월, 비율 = 비율이 가장 큰 달에 넣어 월 합계 = 확정 계획액 (끝수 들어간 칸 왼쪽 위에 노란 표시)
  - 인원 · 단가×수량: 월액(단가) · 인원(수량) · 개월 · 총액 네 칸 중 [자동]을 누른 칸을 나머지로 계산 (역산)
    총액이 비어 있으면 전년 실적 기준. 역산이면 확정 계획액 = 총액
  - [작년처럼]: 전년 월별 실적 비율로 월 분할. [전년 실적 가져오기]에서 1월~12월 열이 있는 파일(더존 손익 출력)을 올리면 월별도 같이 들어감
  - 증감률 칸 색: 전년 대비 ±10% 이상 연하게, ±30% 이상 진하게 (증가 = 빨강, 감소 = 파랑)
  - 계산기(리본 오른쪽 끝): 열어 둔 채로 표의 금액 칸을 누르면 그 금액(원)이 들어감. 결과 한글 표시 · 복사
  - 요약 띠: 도구 줄 오른쪽 [요약 접기], 아래 경계선을 끌어 높이 조절 (더블클릭 = 처음 높이)
  - 리본 묶음: 묶음 오른쪽 끝 ⋮⋮ 를 끌어 같은 탭 안에서 순서 변경 (설정 › 리본 배치 처음대로)
  - ↑↓ 줄 이동, Ctrl+Z 실행 취소 · Ctrl+Y 다시 실행 (최근 100번), Ctrl+F 계정 검색
  - 비고 칸 = 직접 쓴 메모만 보임 (산출 내역은 계획 칸 팝업에서 확인)
  - [보고용 엑셀]: 소계·합계가 들어간 보고용 파일을 내려받기
  - [계획 양식 다운] / [계획 양식 업로드] (리본 [계획] › 데이터): 계정별 산출 방식 · 금액 · 월별 · 비고를 엑셀로 받아
    고친 뒤 올리면 바뀌는 계정을 먼저 보여주고 [적용]. 계정은 ID → 분류 경로 → 더존코드 순으로 맞춤
    산출 방식이 비어 있고 월 금액만 있으면 '수기'로 들어감. 마감된 계획엔 올릴 수 없음([계획 변경] 후)

■ 집행 — 아래 시트 탭 [집행]
  - 더존 자료 넣는 곳: budget\더존원본\2026\  (연도 폴더)
    · 매달 마감 후 1/1~그 달 말 누계로 두 파일을 저장. 파일 이름에 월을 넣기
      예) 분개장_09월.xls (분개장 전체) · 손익_09월.xls (재무제표 손익, 1~9월 선택 출력)
    · 파일 종류는 내용으로 알아봄 (이름의 '분개장' · '손익' 은 없어도 됨, 월 숫자는 필요)
  - [더존 자료 읽기]: ① 파일 확인 → ② 분류에 연결 안 된 더존 과목 (판관비 그룹으로 연결할 분류를 추천, 적용하면 분류 버전이 남음)
    → ③ 지난 달 수정 (전에 읽은 달의 내역이 바뀐 것: 추가 · 삭제 · 금액 바뀜) → ④ 대조 검증
    · 대조 검증: 과목 · 월마다 분개장 합계 = 손익 금액 인지 확인. 하나라도 안 맞으면 저장하지 않고 [반영 기록]에 문제로 남김
  - 저장: budget\data\집행_2026.xlsx (월별 집행 · 메모 · 지난달수정 · 기록), 집행_2026_내역.xlsx (분개장 줄)
  - 표: 달마다 계획 · 집행 · 증감(= 집행 − 계획). 도구 줄 [전체 · 집행만 · 계획만 · 증감만] [월별 · 누계] [~N월까지]
    · 증감 칸 배경색: 계획보다 많이 쓰면 빨강, 덜 쓰면 파랑 (클수록 진하게)
    · 비교: 계획(최종 마감본) / 전년 같은 달 / 올해 월평균
    · 연말 예상 = 집행한 달 + 남은 달 계획
  - 집행 칸 클릭 = 분개장 내역 팝업 (금액 큰 순, 영향도 %) · 일자 · 거래처 · 적요 정렬, 거래처/적요로 묶기,
    중복 의심 표시, 줄별 메모, 전표 보기, 엑셀로 내려받기
  - 칸 우클릭 = 메모 (메모 있는 칸은 모서리 표시, 마우스를 올리면 메모가 뜸). [메모 모아보기]로 전체 확인
  - 집행 금액은 고칠 수 없음 (더존 자료가 기준)
  - 지난 달이 바뀌면 그 칸에 ⚠ 표시 + 리본 [지난 달 수정] 숫자 → 내용 확인 후 [정상 처리] (사유는 선택)
  - [분개장 검색]: 적요 · 거래처 · 금액으로 한 해 내역 전체 검색. [반영 기록]: 읽기 · 정상 처리 · 문제 이력
  - 계획 마감 뒤 새로 생긴 계정은 '계획 외'로 집행만 보임
