인력현황 관리 프로그램 — 테스트판 0.1.3
=====================================

■ 실행
  1) 압축을 풀기 전에: zip 우클릭 → 속성 → [차단 해제] 체크 (있을 때만)
  2) 원하는 곳에 압축 풀기 (예: 바탕화면\인력현황)
  3) 인력현황.html 을 크롬(또는 엣지)으로 열기 — 설치 · 서버 · 인터넷 필요 없음
  4) 처음 한 번 [폴더 연결] → 인력현황.html 이 들어 있는 폴더를 고르기 → [파일 수정 허용]
     (매번 묻지 않게 하려면 [방문할 때마다 허용])

■ 폴더 구조
  인력현황\
  ├─ 인력현황.html            ← 시작 파일
  ├─ app\                     ← 프로그램 (업데이트 때 인력현황.html 과 app 폴더만 바꿈)
  ├─ 백데이터\설정\
  │   ├─ 직원명부\  직원명부_20261030.xlsx …   (파일 이름 뒤 날짜 = 기준일)
  │   ├─ 발령검색\  발령검색_20261030.xlsx …   (지금은 보관만, 인력현황 다음 단계에서 씀)
  │   └─ 조직목록\  조직 목록.xlsx             (바뀔 때마다 보관\조직 목록_날짜.xlsx 로 자동 보관)
  ├─ cache\직원명부\            ← 직원명부를 한 번 읽은 결과 (다음부터 빠르게 열림 · 지워도 됨)
  ├─ data\기준정보.xlsx        ← 설정 · 분류 기준 · 메모가 저장되는 곳 (자동 저장)
  └─ backup\                  ← 기준정보 이전 파일 (30분마다, 최근 30개)
  * 백데이터 · data · backup · cache 폴더가 없으면 프로그램이 만듭니다.

■ 빠르게 열기 (cache)
  - 직원명부는 처음 한 번만 엑셀을 풀어 읽고 cache\직원명부\<파일이름>.dat 로 저장
  - 다음부터는 원본 파일 크기 · 수정 시각이 같으면 캐시를 씀 → 새로 넣거나 고친 명부만 다시 읽음
  - 원본을 지우면 그 캐시도 지움 · cache 폴더를 통째로 지워도 다음에 열 때 다시 만듦 (설정과는 무관)

■ 직원명부 파일 이름
  - 이름 어딘가에 날짜 8자리만 있으면 됨: 20261030.xlsx · 직원명부_20261030.xlsx · 2026-10-30.xlsx 모두 인식
  - 첫 시트 위쪽 10줄 안에 '사번' · '소속' 머리글이 있어야 함
  - 인식 못 한 파일 · 읽다 실패한 파일 · 첫 달과 마지막 달 사이 빠진 달 · 같은 달 여러 파일 · 조직 목록 없음은
    열 때와 ↻ 다시 읽기 때 '백데이터 확인 필요' 창으로 알려 주고, 제목 줄에 노란 [⚠ 백데이터 확인 n] 칩이 남음

■ 처음 쓰는 순서
  1) 백데이터\설정\직원명부 에 직원명부 파일들을 넣기 (한 달에 여러 개면 그달 가장 늦은 날짜 파일을 그달 말 인원으로 씀)
  2) 조직목록 에 '조직 목록.xlsx' 넣기
  3) 프로그램을 열면 [기본 세팅] 창이 뜸 → 기본 세팅 시작
     - 최신 직원명부로 조직(소속6=회사 · 소속5=본부 · 소속4=부서·파트 · 소속3=센터) · 직급 · 직무 기준값을 만듦
     - 조직 목록에만 있는 조직은 '레벨 미정'으로 들어감 → 우클릭 › 수정에서 레벨 · 상위 지정
     - 기본 분류 기준 3개(조직별 · 직급별 · 직무별)가 생김
  4) 설정 › 미매칭: 과거 직원명부의 옛 조직 · 직급 · 직무 이름을 지금 값의 옛 버전으로 연결
     - 줄마다 '연결 대상'에 추천(다음 명부에서 ○○%가 간 곳)이 미리 들어가 있음 · ▾ 로 바꾸기
     - 줄 끝 [확정] = 연결 대상의 옛 이름으로 · [폐지] = 폐지된 값으로 등록 · [신설] = 지금도 쓰는 새 값으로 등록
     - 맨 앞 체크박스로 여러 줄 고르고(Shift+클릭 = 범위) 위 [✓ 확정] · [폐지] · [신설] = 한 번에 (Ctrl+Z 한 번에 되돌림)
     - 열 머리 누르기 = 정렬 · ▾ = 엑셀처럼 값 골라 필터 · 찾기 칸 · [추천 80%↑ 체크] · [⇩ 엑셀]
  5) 설정 › 분류 기준: 카드(조직 · 직무 · 직급 · 직책 · 직군 · ＋종류)를 줄에 끌어다 담아 보고서 줄을 만듦
  6) 인력현황: 분류 기준을 엑셀형 표로 출력

■ 설정 (조직 · 직급 · 직무)
  - 조직은 트리에서 우클릭: 하위 추가 · 같은 레벨 추가 · 수정 · 폐지 · 삭제 (수정 · 폐지 · 삭제는 영향 범위 경고)
  - 수정은 두 가지: '새 버전으로 변경'(이름 변경 · 상위 이동, 기록이 남음) / '현재 버전 바로 고치기'(오타 정정)
  - 직급 · 직무는 항목 우클릭 = 수정 · 순서 · 폐지 · 삭제, 빈칸 우클릭 = 추가
  - Ctrl+Z / Ctrl+Y = 실행 취소 · 다시 실행 (최근 100번)
  - [⇩ 기준값] = 기준정보를 엑셀로 내려받기

■ 분류 기준 (바구니)
  - 같은 종류 카드는 '또는', 다른 종류는 '그리고' · 위 줄(합계 줄)의 카드는 아래 줄 모두에 공통 조건
  - ⚡ 우선 = 이 줄이 사람을 먼저 가져감 (관리자 · 휴직 줄 등) · ↺ 나머지 = 같은 위 줄 안의 남은 사람을 모두 받음
  - 담은 카드를 누르면 그 카드에만 조건(직무 · 직급 · 직책 …)을 걸거나 값마다 쪼개기
  - ＋ 종류 = 직원명부의 다른 열(직군 · 직위 · 입사구분 등)을 카드 종류로 추가 (개인정보 · 날짜 열 제외)
  - 아래 '누락 인력'에 어느 줄에도 안 들어간 사람과 빠진 이유가 나옴 · 묶음 카드를 바로 끌어다 담을 수 있음

■ 인력현황
  - 기준월 · 기간은 달력에서 고름 (흐린 달 = 직원명부 없음) · 월별 / 분기말 / 연말
  - 전월比 · 전년比 · 처음比 · 연평균 · 변화 색칠 켜고 끄기 · 펼침 단계 1 · 2 · 3 · 전체
  - 머리 ▾ = 정렬(계층 유지) · 줄 고르기 · 값 조건 · 열 숨기기 / 칩 [정렬 · 필터 적용 중 ✕] = 모두 해제
  - 끌어서 여러 칸 선택 · 열 문자 / 행 번호 누르기 = 열 · 행 전체 · Ctrl+A = 전체 / Ctrl+C = 복사(엑셀에 붙여넣기)
  - Enter · 더블클릭 = 그달 그 줄 명단 · 우클릭 = 복사 · 명단 · 메모 · 정렬 · 열 숨기기
  - ＋ 시트 = 지금 화면을 복사해 다른 분류 기준 · 기준월로 여러 화면 띄우기 (시트 이름은 더블클릭)
  - ⇩ 보고용 = 지금 표를 엑셀로 · ⇩ 명단 = 기준월 사람별로 어느 줄에 들어갔는지

■ 저장
  - 바뀔 때마다 data\기준정보.xlsx 에 자동 저장 (제목 줄 마스코트가 저장 중엔 바쁘게 움직임)
  - 엑셀로 기준정보.xlsx 를 열어 둔 채면 저장이 실패함 → 엑셀을 닫고 제목 줄 빨간 표시를 누르면 다시 저장
  - 프로그램을 새 버전으로 바꿔도 data 의 파일은 그대로 씀. 형식이 바뀌면 자동으로 변환하고 원본은 backup 에 '기준정보_변환전_…' 으로 남김
  - 시트 · 보기 설정(연평균 등)은 이 PC 브라우저에 기억됨

■ 업데이트 방법 (설정 데이터 보호)
  1) 프로그램을 닫기
  2) 새 zip 의 인력현황.html 과 app 폴더만 기존 폴더에 덮어쓰기
     - 백데이터 · data · backup 폴더는 건드리지 않음 (새 zip 에는 이 폴더가 들어 있지 않음)
  3) 다시 열면 자동으로:
     - 프로그램 버전이 바뀐 걸 알아채고, 기존 data\기준정보.xlsx 를 backup\기준정보_업데이트전_v옛버전_날짜.xlsx 로 먼저 복사
     - 저장 형식이 바뀐 버전이면 변환 전에 backup\기준정보_변환전_… 로 한 번 더 복사한 뒤 변환
     - 새 프로그램이 모르는 시트 · 열은 지우지 않고 그대로 보존
  4) 혹시 이상하면: 설정 › ⟲ 백업 복원 → '프로그램 업데이트 직전' 줄의 [이걸로 되돌리기]

■ 데이터 보호 장치
  - 저장할 때마다 다시 읽어 확인 → 내용이 다르면 직전 파일로 자동으로 되돌림
  - 조직 · 직급 · 직무 · 분류 기준이 갑자기 0개가 되거나 분류 줄이 절반 아래로 줄면 저장을 멈추고 물어봄
  - backup 폴더: 30분 자동(최근 30개) · 그날 첫 저장 전(지우지 않음) · 업데이트 직전 · 변환 직전 · 되돌리기 직전
  - 설정 › ⟲ 백업 복원: 백업마다 조직 · 직급 · 직무 · 분류 기준 개수를 보여주고 골라서 되돌림 (지금 파일은 먼저 보관)
  - 오래된 프로그램으로 새 형식 파일을 열면 읽기 전용 (저장 안 함)
  - data 폴더째로 USB · 공유 폴더에 복사해 두면 그게 가장 확실한 백업입니다
