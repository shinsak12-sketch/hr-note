# 톱 (TOB) — SHIN 프로그램 공통 서명 캐릭터

내가 만드는 모든 프로그램에 붙는 서명 캐릭터. 프로그램이 달라도 같은 모양 · 같은 색 · 같은 쓰임새로 씀.

- 이름: **톱** (TOB) — 쉬지 않고 도는 톱니
- 서명 문구: **Made by SHIN**
- 첫 적용: 인력관리 프로그램 v1.5 (가동률 · 생산성 · 추출보드)
- 파일: `tob.js` 하나 (의존성 없음, CSS 포함) · `demo.html` 은 브라우저로 바로 열어 보는 견본

---

## 1. 디자인 원칙

- **단색 덩어리 + 눈 두 칸 + 한두 칸짜리 팔다리**만 씀
- 입 · 볼 · 옷 · 소품 같은 디테일은 넣지 않음. 실루엣만으로 알아보게 함
- 상태는 **눈 · 팔 · 다리 · 톱니 속도**로만 표현함
- 움직임은 **한 칸씩 끊어서** (CSS `steps()`) — 부드러운 보간 쓰지 않음
- 12px 까지 줄여도 알아봐야 함

## 3. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 호박 (몸) | `#EBA21E` | 톱 몸 · 팔 · 다리 · 톱니 |
| 먹 (눈) | `#1A1F1C` | 눈 |
| 초록 (바탕) | `#1D7A4C` | 크게 놓을 때의 받침 · 이스터에그 조각 |
| 연호박 | `#F6D58E` | 이스터에그 먼지 |

- 호박은 초록 바탕 대비 2.5 : 1, 흰 바탕 대비 2.2 : 1 — 둘 다에서 또렷함
- 프로그램 기본색이 초록이 아니어도 몸 색은 **호박 그대로** 둠 (서명이니까 바꾸지 않음)
- 진한 색 바탕 위에서도 호박 그대로, 눈만 먹색

## 4. 상태 4가지

| 상태 | 코드 | 눈 | 팔 | 다리 · 톱니 | 쓰는 때 |
|---|---|---|---|---|---|
| 기본 | `base` | ■ ■ (가끔 깜빡임) | 가운데 | 가만히 · 톱니 1.2초 | 평소 · 빈 화면 |
| 계산 중 | `work` | ■ ■ 옆으로 왔다 갔다 | 가운데 | 번갈아 걸음 · 톱니 0.4초 | 읽기 · 계산 · 저장 중 |
| 완료 | `done` | ^ ^ | 위로 듦 | 가만히 | 저장 · 내보내기 끝 · 알림 없음 |
| 오류 | `oops` | — — | 아래로 처짐 | 가만히 | 실패 · 파일 없음 · 결과 없음 |

움직임 타이밍: 둥실 1.4초 · 깜빡 3.6초 · 걷기 0.5초 · 톱니 1.2초(계산 중 0.4초). 전부 `steps(1)`.
`prefers-reduced-motion` 이면 모두 멈춤.

## 6. 이름 · 서명 규칙

- 프로그램 이름은 기능이 아니라 **넓은 이름**으로 (예: '가동일 계산' ✕ → **인력관리 프로그램** ○). 나중에 기능이 늘어도 이름이 맞게
- 프로그램 정보 · 엑셀로 내보낸 파일의 정보 칸 · 인쇄 머리에 **Made by SHIN**
- 프로그램 정보 화면: 초록 받침 위 큰 톱(done) + 이름 + 버전 + `Made by SHIN`

## 7. 이스터에그

- **켜는 법**: 머리줄 앱 이름 옆 톱을 누름 (프로그램 정보는 다른 메뉴에서 열게 둠)
- **동작**
  1. 머리줄 톱이 사라지고 화면으로 뛰어나옴
  2. 화면 여기저기 6~8번 깡충 — 매번 위치 · 높이 · 속도가 다름
  3. 뛸 땐 work, 세 번째마다 done · 착지할 때 찌그러졌다 펴짐 · 발밑 호박 먼지
  4. 왼쪽으로 갈 땐 몸을 뒤집음
  5. 마지막에 높이 뛰며 한 바퀴 돌고 작아지다가 호박 · 초록 조각으로 펑
  6. 0.65초 뒤 머리줄 제자리에 쏙 다시 나타남
- **지킬 것**: 뛰는 동안 화면 조작을 막지 않음 (`pointer-events: none`) · 뛰는 중 다시 눌러도 겹치지 않음 · 움직임 줄이기 설정이면 살짝 사라졌다 돌아오기만 · 도움말에는 안 적음 (숨은 기능)

## 8. 코드로 붙이기

```html
<script src="brand/tob/tob.js"></script>

<!-- 머리줄: 누르면 이스터에그 -->
<span data-tob="base" data-tob-size="28" data-tob-egg></span> 인력관리 프로그램

<!-- 상태줄: 오래 걸리는 일 할 때 Tob.busy(true) -->
<span data-tob-busy data-tob-size="16"></span>

<!-- 프로그램 정보 서명 -->
<div id="sig"></div>
<script>Tob.favicon("base"); Tob.signature("#sig", "인력관리 프로그램");</script>
```

```js
toast.innerHTML = Tob.svg(isError ? "oops" : "done", { size: 20 }) + msg;   // 알림
empty.innerHTML = Tob.svg("oops", { size: 64 }) + "맞는 결과 없음";           // 빈 결과
Tob.busy(true); await longJob(); Tob.busy(false);                             // 오래 걸리는 일
```

React 에서는 `dangerouslySetInnerHTML={{ __html: Tob.svg("base", { size: 28 }) }}` 로 넣거나, 마운트 후 `Tob.auto()` 호출.
