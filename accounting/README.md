# 경리 콕핏 (오프라인 사업비 관리)

서버 없이 내 PC에서 동작하는 사업비·수수료 관리 프로그램입니다.
크롬에서 **폴더 하나를 연결**하면 그 폴더의 엑셀을 읽고, 계획·설정을 같은 폴더에 저장합니다.
데이터는 전부 내 PC에만 남습니다.

## 실행 방법

폴더 연결 기능(File System Access API)은 보안상 `localhost`에서만 동작하므로,
HTML을 더블클릭(`file://`)하면 안 되고 아래처럼 로컬 서버로 띄웁니다. (Node.js 필요)

- **Windows**: `START-Windows.bat` 더블클릭 (Node.js 없이 PowerShell로 실행됨)
- **Mac**: `START-Mac.command` 더블클릭 (최초 1회: 우클릭 → 열기)
- **직접 실행**: 이 폴더에서 `node server.js` → 브라우저가 자동으로 `http://localhost:4173` 을 엽니다.

> Windows는 내장 PowerShell로 실행되어 별도 설치가 필요 없습니다.
> Mac은 Node.js 또는 python3 중 하나가 필요합니다.

## 처음 사용 순서

1. 앱에서 **폴더 연결하기** → 데이터를 저장할 빈 폴더 선택
2. **기준정보 → 템플릿 엑셀 생성** → 폴더에 아래 엑셀들이 생성됨
3. 엑셀을 열어 실제 계정·단가·유형으로 편집 후 저장
4. 앱에서 **다시 읽기** → 반영 확인
5. 먼저 둘러보려면 **샘플로 둘러보기** (폴더 없이 3D 미리보기)

## 폴더 구조 / 파일 규약

```
[연결한 폴더]/
  계정항목.xlsx      코드 | 대분류 | 중분류 | 소분류
  수수료단가.xlsx    유형코드 | 사고유형 | 구간 | 단가유형(정액/정률) | 단가
  사고유형.xlsx      유형코드 | 사고유형 | 설명
  2026/
    실적_사업비.xlsx    (다음 단계) 코드 × 월별 집행액
    실적_처리건수.xlsx  (다음 단계) 유형 × 월별 건수
    plan.json           앱이 저장하는 계획(산출근거)
    settings.json       앱이 저장하는 현금흐름 가정
```

- 각 마스터 엑셀의 **코드** 열은 바뀌지 않는 식별자입니다.
  이름(대/중/소분류)은 자유롭게 바꿔도 코드만 유지되면 데이터가 안전하게 따라옵니다.

## 구현 현황

- ✅ 폴더 연결 · 엑셀 읽기 · 템플릿 생성 · 기준정보 · 설정 · **3D 사업비 도시(대시보드)**
- ⏳ 다음: 사업비 계획(롤링) → 실적 읽기 → 계획 vs 실적 → 수입/수수료 → 손익·현금흐름

## 기술

순수 HTML/CSS/JS + [SheetJS](https://sheetjs.com) (엑셀, `vendor/`에 오프라인 번들).
3D는 외부 라이브러리 없이 CSS 3D 트랜스폼으로 구현했습니다.
