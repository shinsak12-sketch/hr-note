# 경리 콕핏 (무설치 · 오프라인 사업비 관리)

설치·서버 없이 **`index.html`을 더블클릭**하면 바로 실행되는 사업비/수수료 관리 프로그램입니다.
데이터는 전부 내 PC에만 있습니다.

## 실행 방법

1. 압축을 풀고 폴더 전체를 원하는 위치에 둡니다.
2. **`index.html` 더블클릭** → 크롬(또는 엣지)에서 열립니다.
   - 다른 브라우저로 열리면: index.html 우클릭 → 연결 프로그램 → Chrome 선택.

> 서버·Node.js·관리자 권한이 필요 없습니다. 인터넷도 필요 없습니다.

## 처음 사용 순서

1. 첫 화면에서 **📥 템플릿 엑셀 내려받기** → 다운로드 폴더에 엑셀 3개 생성
   (`계정항목.xlsx`, `수수료단가.xlsx`, `사고유형.xlsx`)
2. 이 엑셀들을 **데이터 폴더**(예: `내문서\경리데이터`)로 옮기고, 엑셀로 실제 값 편집
3. 앱에서 **📂 폴더 선택해서 읽기** → 그 폴더 선택
4. 대시보드(3D)·기준정보에서 결과 확인
5. 그냥 둘러보려면 **✨ 샘플로 둘러보기**

## 데이터가 저장되는 곳

- **마스터 엑셀**(계정·수수료·사고유형): 내가 고른 폴더의 엑셀 파일 (엑셀에서 직접 편집)
- **앱 설정·계획**: 이 브라우저에 저장(localStorage). 백업은 설정 화면의 **내려받기(.json)** 사용
- 한 번 읽은 데이터는 브라우저에 기억되어, 다시 열면 바로 보입니다. (엑셀을 고쳤으면 **다시 읽기**)

## 엑셀 규약 (코드 = 안 바뀌는 식별자)

```
계정항목.xlsx   : 코드 | 대분류 | 중분류 | 소분류
수수료단가.xlsx : 유형코드 | 사고유형 | 구간 | 단가유형(정액/정률) | 단가
사고유형.xlsx   : 유형코드 | 사고유형 | 설명
```
이름(대/중/소분류)은 자유롭게 바꿔도, **코드**만 유지되면 데이터가 안전하게 따라옵니다.

## 구현 현황

- ✅ 폴더 읽기 · 템플릿 내려받기 · 기준정보 · 설정 · **3D 사업비 도시(대시보드)**
- ⏳ 다음: 계정 자유 배치(드래그) · 사업비 계획(롤링) · 실적 · 계획 vs 실적 · 수입/수수료 · 손익·현금흐름

## 기술

순수 HTML/CSS/JS(일반 스크립트) + [SheetJS](https://sheetjs.com)(엑셀, `vendor/`에 오프라인 번들).
3D는 외부 라이브러리 없이 CSS 3D 트랜스폼으로 구현.
