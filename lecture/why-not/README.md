## 서론 (17장)
1. 오프닝 영상 — 같은 폴더에 `opening.mp4`를 두면 재생 (H.264여야 함)
2. 표지 Why not?
3. 설문 QR(9문항 · 1분) + 결과 보기(강사 화면 → `←` `→`로 문항별 결과)
4. AI에 실망한 순간(1박 2일 여행지 질문) / 다른 질문도 뻔하다 → "실망하셨다면 AI를 잘못 쓰고 계신 겁니다"
5. AI 원리 4컷 만화 / 몬테카를로 사람 vs AI(`▶ 재생`: 사람은 공식, AI는 무작위 점 5만 개) / 결론: 일을 시켜서 나를 돕는 도구로
6. Why Now? 질문 → 모델 출시 연표(몇 개월마다 새 모델, 이건 시작) → 사람을 넘다 5장(바둑 → 코딩 → 수학 난제 → 사람만 풀던 시험 → 인류의 마지막 시험) → 더 똑똑하고 싸진다 → **Why Now의 답: 아직 6시간 차이, 지금 시작해야 한다**
