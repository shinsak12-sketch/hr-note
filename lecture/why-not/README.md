# Why not? — 생성형 AI 활용 업무 보조 바이브코딩 (3시간)

새로 짜는 강의안입니다. 한 주제는 1~2장 안으로 만듭니다. 지금은 **서론 · 1부(챕터 1~3) · 2부 바이브코딩**까지 전부 들어 있습니다(86장).
`index.html`을 브라우저로 열고 `F`로 전체화면. `fonts/`를 같은 위치에 두세요.

- 기초 가이드 8단계: ① 목표=개성 → ② 뼈대 · 구조(개인용/공유용 · 오프라인/온라인 · 웹/앱 · 프론트엔드/백엔드 · 언어 표기만) → ③ 디자인 시안 → ④ 검증 대화 → ⑤ 프로토타입 → ⑥ 결과물 · 세부 작동 → ⑦ 고칠 땐 캡처 → ⑧ 오류엔 닦달 말고 점검 요청
