# 바이브코딩 강의 (2시간, 비개발 직군 입문)

3년차 미만 실무자 대상 **AI 바이브코딩** 2시간 강의용 인터랙티브 발표 자료입니다.
파워포인트가 아니라 브라우저에서 바로 발표하는 **HTML 프로그램**이라, 강의 첫머리에서
"이 자료도 바이브코딩으로 만들었습니다"라고 그대로 보여줄 수 있습니다.

## 여는 법
- `lecture/index.html` 파일을 **브라우저로 열기** (더블클릭)
- 인터넷이 없어도 동작합니다. (온라인이면 Pretendard 폰트로 더 깔끔하게 표시)

## 발표 단축키
| 키 | 기능 |
|---|---|
| `→` `←` `Space` | 다음 · 이전 슬라이드 |
| `Home` `End` | 처음 · 마지막 |
| `F` | 전체화면 |
| `T` | 발표 타이머(2시간) 켜기 — 자동 시작 |
| `N` | 강사 노트 보기/숨기기 (진행 멘트·타이밍 포함) |
| `O` | 전체 슬라이드 목록 → 클릭 이동 |
| `D` | 라이트/다크 전환 |
| `?` | 단축키 도움말 |

- 화면 우하단/우상단 버튼으로도 조작 가능, 태블릿은 좌우 스와이프.
- 주소 끝에 `#22`처럼 붙이면 해당 슬라이드로 바로 이동.

## 구성 (총 120분)
1. 도입 — 바이브코딩이 뭐길래 (15분)
2. 원리 — AI와 대화하는 법 / 좋은 요청의 4요소 (20분)
3. 라이브 데모 — claude.ai에서 직접 시연 (15분)
4. 휴식 (10분)
5. 실습 1 — 내 도구 만들기 (35분)
6. 실습 2 — 다듬고 공유 (15분)
7. 마무리 — 실무 적용 · 주의사항 · Q&A (10분)

## 강사 팁
- 각 슬라이드의 **강사 노트(`N`)**에 멘트와 타이밍 큐가 들어 있습니다.
- 데모(3부)와 실습 준비(5부)에서 **미리 claude.ai 로그인**을 안내하세요.
- 실습 중에는 `O`로 "좋은 요청 4요소", "마법의 문장들", "실습 팁" 슬라이드를 다시 띄우면 유용합니다.

## 수정하고 싶다면
문구·순서·색을 바꾸려면 `index.html`을 열어 해당 `<section class="slide">`를 편집하거나,
AI에게 이 파일을 주고 "이 부분을 이렇게 바꿔줘"라고 요청하면 됩니다 — 그것도 바이브코딩입니다.
