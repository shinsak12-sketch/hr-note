# 바이브코딩 강의 (2시간, 비개발 직군 입문)

3년차 미만 실무자 대상 **AI 바이브코딩** 2시간 강의용 인터랙티브 발표 자료입니다.
파워포인트가 아니라 브라우저에서 바로 발표하는 **HTML 프로그램**이라,
강의 첫머리에서 "이 자료도 바이브코딩으로 만들었습니다"라고 그대로 보여줄 수 있습니다.

## 핵심 컨셉 — 이론보다 "직접 만드는 걸 보여준다"
- 앞부분: 바이브코딩이 뭔지 **짧게**만 (5장)
- **하이라이트(STEP 2)**: 강사(나)와 Claude의 **실제 채팅 대화**를 슬라이드에 그대로 보여주고,
  각 대화 다음에 **실제로 작동하는 결과물**을 슬라이드 안에 임베드.
  요청 → 결과 → "이렇게 바꿔줘" → 개선된 결과, 이렇게 **대화 3번**으로
  '점심 메뉴 랜덤 추천기'가 완성되는 과정을 눈으로 보여줍니다.
  → 결과물 v1·v2·v3 **모두 슬라이드 안에서 실제로 클릭돼서 작동**합니다.
- 뒷부분(STEP 3~4): 이제 여러분 차례(실습) → 정리 & Q&A

## 여는 법
- `lecture/index.html` 파일을 **브라우저로 열기** (더블클릭)
- 인터넷이 없어도 동작합니다. (온라인이면 Pretendard 폰트로 더 깔끔하게)

## 발표 단축키
| 키 | 기능 |
|---|---|
| `→` `←` `Space` | 다음 · 이전 |
| `Home` `End` | 처음 · 마지막 |
| `F` | 전체화면 |
| `T` | 발표 타이머(2시간) 켜기 — 자동 시작 |
| `N` | 강사 노트 보기/숨기기 (진행 멘트·타이밍 포함) |
| `O` | 전체 슬라이드 목록 → 클릭 이동 |
| `D` | 라이트/다크 전환 |
| `?` | 단축키 도움말 |

> 💡 **완성본 슬라이드(#14)의 입력창에 스페이스·한글을 쳐도 슬라이드가 넘어가지 않습니다.**
> 라이브로 메뉴를 추가/삭제하며 시연해도 안전합니다.

## 라이브 시연 팁 (STEP 2)
- 슬라이드에 담긴 대화는 예시입니다. 실제 강의에서 **claude.ai를 열고 그대로 재현**해도 좋고,
  네트워크가 불안하면 슬라이드의 임베드 결과물로 바로 시연해도 됩니다.
- 완성본(#14)에서 **청중에게 "근처 맛집 하나 외쳐보세요"** → 즉석에서 메뉴 추가 → "돌리기!"로
  참여를 끌어내면 몰입도가 확 올라갑니다.
- 만들 프로그램을 바꾸고 싶으면(예: 연차 계산기) 말씀 주세요. 대화·결과물을 통째로 교체해 드립니다.

## 구성 (총 21장 / 120분)
1. 도입 — 바이브코딩이 뭔지 (STEP 1, ~15분)
2. **같이 만들기** — 채팅 3번으로 점심 메뉴 추천기 완성 (STEP 2, ~35분)
3. 실습 — 각자 도구 만들기 (STEP 3, ~50분)
4. 정리 · 주의사항 · Q&A (STEP 4, ~20분)

## 수정하고 싶다면
문구·순서·색을 바꾸려면 `index.html`을 열어 해당 `<section class="slide">`를 편집하거나,
AI에게 이 파일을 주고 "이 부분 이렇게 바꿔줘"라고 요청하면 됩니다 — 그것도 바이브코딩입니다.
