# 바이브코딩 강의 (2시간, 비개발 직군 입문)

3년차 미만 실무자 대상 **AI 바이브코딩** 2시간 강의용 인터랙티브 발표 자료입니다.
파워포인트가 아니라 브라우저에서 바로 발표하는 **HTML 프로그램**이라,
강의 첫머리에서 "이 자료도 바이브코딩으로 만들었습니다"라고 그대로 보여줄 수 있습니다.
**빔 프로젝터 대형 화면 기준**으로 글씨·요소를 큼직하게 맞췄습니다.

## 핵심 컨셉 — 이론보다 "직접 만드는 걸 보여준다"
- 앞부분(STEP 1): 바이브코딩이 뭔지 **짧게**만
- **하이라이트(STEP 2)**: 강사(나)와 Claude의 **실제 채팅 대화**를 보여주고,
  각 대화 다음에 **실제로 작동하는 결과물**을 슬라이드 안에 임베드.
  대화 **3번**으로 "우리 센터 점심 매니저"가 이렇게 커집니다:
  1. **1단계 — 메뉴 추천**: 한/양/일/중 분류별(각 7개) 슬롯머신 추천
  2. **2단계 — 기록 & 통계**: 맛집·반응 기록 → 최근 7일/이번 달 횟수, 분류별 막대,
     '자주 먹은 메뉴' 알림 (기록하면 통계가 **즉시** 갱신되는 게 라이브 하이라이트)
  3. **3단계 — 과비 가계부**: 참여자별 금액 입력 → 잔액 자동 계산 + 충전/지출 장부
  → 완성본(#14)은 **[추천·통계·과비] 탭** 앱으로, 슬라이드 안에서 전부 작동합니다.
- 뒷부분(STEP 3~4): 이제 여러분 차례(실습) → 정리 & Q&A

## 여는 법
- `lecture/index.html` 파일을 **브라우저로 열기** → `F`로 전체화면
- 인터넷이 없어도 동작합니다. (온라인이면 Pretendard 폰트로 더 깔끔하게)

## 발표 단축키
| 키 | 기능 |
|---|---|
| `→` `←` `Space` | 다음 · 이전 |
| `Home` `End` | 처음 · 마지막 |
| `F` | 전체화면 |
| `T` | 발표 타이머(2시간) 켜기 — 자동 시작 |
| `N` | 강사 노트 보기/숨기기 (진행 멘트·타이밍 포함) |
| `O` | 전체 슬라이드 목록 → 클릭 이동 |
| `D` | 라이트/다크 전환 |
| `?` | 단축키 도움말 |

> 💡 앱의 입력창(맛집·이름·금액)에 **한글·스페이스·숫자를 쳐도 슬라이드가 넘어가지 않습니다.**
> 라이브로 기록·지출을 입력하며 시연해도 안전합니다.

## 라이브 시연 팁 (STEP 2)
- 슬라이드 대화는 예시입니다. 실제로 **claude.ai를 열고 재현**해도 좋고,
  네트워크가 불안하면 슬라이드의 임베드 결과물로 바로 시연해도 됩니다.
- **#12(2단계)**: 왼쪽에서 메뉴 뽑고 맛집 적고 '기록하기' → 오른쪽 통계 숫자·막대가 바뀌는 걸 보여주세요.
- **#14(완성)**: 탭을 오가며 → [추천]에서 뽑고 기록 → [통계]에서 반영 확인 → [과비]에서
  참여자·금액 넣고 '지출 기록' → 잔액이 줄고 가계부에 쌓이는 걸 시연. 청중에게
  "근처 맛집 하나 외쳐보세요" → 즉석 추가하면 몰입도가 확 올라갑니다.
- 만들 프로그램/시나리오를 바꾸고 싶으면 말씀 주세요. 대화·결과물을 통째로 교체해 드립니다.

## 구성 (총 21장 / 120분)
1. 도입 — 바이브코딩이 뭔지 (STEP 1, ~15분)
2. **같이 만들기** — 채팅 3번으로 점심 매니저(추천→통계→과비) 완성 (STEP 2, ~40분)
3. 실습 — 각자 도구 만들기 (STEP 3, ~45분)
4. 정리 · 주의사항 · Q&A (STEP 4, ~20분)

## 수정하고 싶다면
문구·순서·색을 바꾸려면 `index.html`을 열어 해당 `<section class="slide">`를 편집하거나,
AI에게 이 파일을 주고 "이 부분 이렇게 바꿔줘"라고 요청하면 됩니다 — 그것도 바이브코딩입니다.
