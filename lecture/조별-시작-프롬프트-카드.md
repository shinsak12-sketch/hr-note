# 조별 미션 · 시작 프롬프트 카드

> 각 조에 인쇄해서 나눠주세요. AI 챗봇(**claude.ai · ChatGPT** 등) 아무거나 OK.
> 핵심은 **① 말로 설명 → ② "이렇게 바꿔줘" 반복**입니다. 한 번에 완성 안 돼도 정상!

---

## 1. 먼저 채우세요 — 좋은 요청 4요소

| 요소 | 우리 조 내용 |
|---|---|
| ① **무엇을** 만들지 | (예: 연차 계산기) |
| ② **누가·언제** 쓰나 | (예: 우리 팀이 입사일 넣으면) |
| ③ **어떻게 보이길** | (예: 웹페이지, 버튼 하나, 깔끔하게) |
| ④ **예시·규칙(조건)** | (예: 1년 미만은 매월 1개…) |

---

## 2. 이대로 복사해서 첫 요청으로 보내기 (빈칸만 채우기)

```
나는 우리 회사 ____팀에서 일해.
[ ____________(무엇을) ] 를 만들어줘.

- 누가 쓰나: ____________
- 이렇게 보이면 좋겠어: 설치 없이 브라우저에서 바로 열리는 웹페이지 하나,
  깔끔하고 버튼은 크게. 우리말로.
- 꼭 지킬 규칙/조건: ____________

전문용어 없이, 초보도 이해하게 설명해주면서 만들어줘.
```

---

## 3. 결과가 나오면 — "이렇게 바꿔줘" 반복 (마법의 문장)

- "좋아, 그런데 **○○를 △△로** 바꿔줘"
- "○○가 이상해. 화면에 이렇게 나와 → (그대로 복붙) **고쳐줘**"
- "디자인 더 **깔끔하게** / 글씨 **크게** / **모바일**에서도 잘 보이게"
- "**결과를 복사·저장**하는 버튼 추가해줘"
- "**초등학생도 알게** 쉽게 설명해줘"
- "이거 **안전한지 / 문제 없는지** 알려줘"

---

## 4. 참고 — 강의 데모 '점심 매니저'를 만든 실제 프롬프트 3개

그대로 따라 만들어봐도 좋습니다. (한 번에 하나씩 순서대로)

**① 만들기**
```
내가 우리 센터 막내라 매일 점심 메뉴를 정해야 해.
네가 우리 센터 막내라 생각하고 점심 메뉴 자동 추천 프로그램을 만들어줘.
한식·양식·일식·중식으로 분류되고, 각 분류마다 점심 먹기 좋은 음식이
5개씩은 들어 있어야 해.
```

**② 기능 추가 (기록·통계)**
```
잘 쓰고 있는데 통계가 없네.
오늘 먹은 메뉴를 직원(수석님)별로 좋아요/별로를 체크해 기록하고,
맛집은 어디였는지도 남기게 해줘.
이번 주·이번 달에 뭘 몇 번 먹었는지, 한·양·일·중은 각각 몇 번인지
데이터를 쌓아서, 너무 자주 먹거나 겹치는 걸 알려주는 참고자료도 나오게 해줘.
```

**③ 기능 추가 (과비 가계부)**
```
우리가 밥 먹고 과비로 결제하거든. 근데 과비를 아직 수기로 관리해.
일자는 달력에서 고르고, 먹은 음식은 목록에서 선택하고,
그날 각자 얼마씩 냈는지 넣으면
잔액이랑 가계부 형태까지 연결해서 관리되게 만들어줘.
```

## ⚠️ 꼭 지킬 것
- **민감정보 입력 금지**: 주민번호·개인정보·회사 기밀은 넣지 않기
- **결과는 사람이 검증**: 특히 계산·법규·금액
- **회사 보안·규정 확인 후** 실제 업무에 반영
