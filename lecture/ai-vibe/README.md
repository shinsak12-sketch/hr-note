# 생성형 AI 활용 업무 보조 바이브코딩 (2시간)

오프라인 발표용 덱입니다. `index.html`을 브라우저로 열고 `F`로 전체화면.
`fonts/` 폴더를 같은 위치에 두면 인터넷 없이도 글꼴이 그대로 나옵니다.
(QR 장의 사이트와 진단 화면을 쓰려면 인터넷 필요)

## 구성 (81장, 실습 없이 강의 · 시연)
- **시작 · AI 활용 등급 진단 (8분)** — 진단 사이트 QR(오늘 날짜 방). 강사 PC는 진단 사이트 `/host`
- **1부 업무 자동화하기 (55분)**
  1. AI는 왜 마법 같은가 — 만화로 보는 "오픈북 시험 보는 학생" 이야기: 한 장짜리 오픈북 → 남의 오픈북 베끼기(읽은 양 15조+, 48만 년) → 너무 오래 걸림(3.8×10²⁵번, 236억 년) → 빠른 손과 1만 6천 명(반도체 1초 1,000조 번) → 정리표 → 주사위로 뽑기 → 없으면 지어내기(환각) → 몬테카를로 체험 → 알파고 → 생각 모드 → **만화의 결론: 묻지 말고 시켜라** → 초안은 AI, 판단은 나
  2. 지금 AI는 어디로 가나 — AI 모델 출시 연표(2018~2026 회사별 점도표), 대답하는 AI에서 일하는 AI(에이전트)로, METR 과제 길이 7개월마다 2배, 맥킨지 2025, 마이크로소프트 Work Trend Index 2026
  3. 매번 설명하지 않게 — 맞춤 지침 · 프로젝트 · 메모리, **학습이 아니라 메모라이징(손이 간다)**, 시키는 방식 두 가지(체계적 프롬프트 / 깊이 대화하기 · 창조론 vs 진화론 토론), 5요소, 역질문, 요청문도 AI가, 프롬프트 자동화 추세, 보안
  4. AI가 직접 문서를 만든다 — 엑셀 · 워드 · PPT · PDF, 시연
  5. 스킬 — **스킬 만화(매번 설명 vs "분쟁심의!" 한마디)**, 명함 · 서랍 · 매뉴얼 비유, SKILL.md 생김새, 만드는 법, 자주 쓰는 프롬프트는 스킬로, 시연 · 분쟁심의위원회 자료 작성(강사가 Claude로 별도 진행)
  6. 1부 정리 → 쉬는 시간 5분 (타이머)
- **2부 바이브코딩 · 상급자 영역 (45분)**
  1. 이론 먼저 (만화) — 1부의 한계: AI 도구 상자 안의 도구만 → 없으면 말로 만든다(바이브코딩) → 어떻게 가능? 오픈북 속 코드 약 17% → 자유도 게이지 10 / 60 / 100
  2. 만드는 법 — 실제 순서 4단계(채팅창 → 미리 보기 → .html 저장 · 더블클릭 → 공유), 3박자(경과일 계산기 예시), 수첩과 게시판(파일 하나의 한계), 첫 요청 템플릿 + 센터원으로 채운 예
  3. 제작 예시(시연) — 센터원 업무 공유 프로그램: 공지 · 할 일(날짜 · 담당자) → 주소록 · 비상연락망 → 메신저 → 다 같이 쓰려면? (폰 화면에서 실제로 눌러지는 결과물, 가짜 예시 데이터)
     - 마지막에 진짜 사이트 QR(`/center?room=오늘날짜`)로 다 같이 써 보기
- **마무리 (8분)** — 오늘의 여정(Lv.1 묻는 사람 → Lv.2 시키는 사람 → Lv.3 만드는 사람), 오늘의 한 문장, 내일부터 딱 세 가지, 감사합니다 · Q&A

화면은 모두 위쪽 정렬(위 여백 넉넉히)입니다(표지 · 구분 장 · 한 문장 · 쉬는 시간만 가운데).

장마다 메시지 문장 + 2~3문장 설명 + 키워드 · 예시로 구성했습니다. 수치 · 사례는 각 장 하단과 강사 노트(`N`)에 출처가 있습니다. 화면이 작아 내용이 넘치는 장은 자동으로 살짝 줄여서 맞춥니다. 메뉴 이름 · 요금제별 제공 범위는 강의 직전 실제 화면으로 확인하세요.

## 사이트 주소
QR이 가리키는 주소는 `index.html` 맨 아래 `LIVE_BASE` 한 줄에서 바꿉니다 (지금: `https://ai-level-survey-weld.vercel.app`).
강의 전에 `/center?room=오늘날짜(예: 261013)`에 들어가 "예시 데이터로 채워 보기"를 눌러 두면 빈 화면 없이 시작합니다.

## 단축키
| 키 | 기능 |
|---|---|
| `→` `←` `Space` | 다음 · 이전 |
| `F` | 전체화면 |
| `N` | 강사 노트 (진행 멘트 · 시간 · 출처) |
| `O` | 전체 슬라이드 목록 |
| `D` | 라이트 / 다크 |
| `숫자` + `Enter` | 그 장으로 바로 이동 (예: `37` Enter) |

## 발표 도구 (오른쪽 아래 도구 막대 또는 키)
| 키 | 기능 |
|---|---|
| `P` | 펜 — 장마다 필기가 따로 남음 |
| `H` | 형광펜 |
| `E` | 이 장 필기 지우기 |
| `L` | 레이저 포인터 |
| `Z` | 확대 — 마우스로 이동, 휠로 배율 |
| `S` | 스포트라이트 — 휠로 크기 |
| `B` / `W` | 검은 화면 / 흰 화면 (다시 누르면 돌아옴) |
| `Esc` | 도구 끄기 |
