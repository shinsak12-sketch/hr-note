# 생성형 AI 활용 업무 보조 바이브코딩 (2시간)

오프라인 발표용 덱입니다. `index.html`을 브라우저로 열고 `F`로 전체화면.
`fonts/` 폴더를 같은 위치에 두면 인터넷 없이도 글꼴이 그대로 나옵니다.
(QR 장의 사이트와 진단 화면을 쓰려면 인터넷 필요)

## 구성 (78장, 실습 없이 강의 · 시연)
- **시작 · AI 활용 등급 진단 (8분)** — 진단 사이트 QR(오늘 날짜 방). 강사 PC는 진단 사이트 `/host`
- **1부 업무 자동화하기 (55분)**
  1. AI는 왜 마법 같은가 — 질문 세 개로: 뭘 하는 기계인가(엄청나게 큰 자동완성) / 왜 잘하나(읽은 양 · 계산력) / 왜 틀리나(뽑기 · 몬테카를로 체험 · 알파고 · 생각 모드) → 초안은 AI, 판단은 나
  2. 지금 AI는 어디로 가나 — 대답하는 AI에서 일하는 AI(에이전트)로, METR 과제 길이 7개월마다 2배, 맥킨지 2025, 마이크로소프트 Work Trend Index 2026
  3. 매번 설명하지 않게 — 맞춤 지침 · 프로젝트 · 메모리, 시키는 방식 두 가지(체계적 프롬프트 / 대화로 풀어 가기), 5요소, 역질문, 요청문도 AI가, 프롬프트 자동화 추세(컨텍스트 엔지니어링 · 메타 프롬프팅 · 에이전트 루프), 보안
  4. AI가 직접 문서를 만든다 — 엑셀 · 워드 · PPT · PDF, 시연
  5. 스킬 — 명함 · 서랍 · 매뉴얼 비유, SKILL.md 생김새, 스킬 감, 만드는 법, 자주 쓰는 프롬프트는 스킬로, 시연
  6. 반복 업무 예약 — ChatGPT 예약 작업, Claude Cowork 예약 작업
  7. 1부 정리 → 쉬는 시간 5분 (타이머)
- **2부 바이브코딩 (45분)**
  1. 시연 두 가지 (보상 카메라 어플 · AI 차량손해사정 — 표지만)
  2. 바이브코딩이란 — 유래, 정의, HTML 파일 하나인 이유, 되는 것 / 안 되는 것, 5가지 형태, 3박자, 첫 요청 템플릿, 막혔을 때
  3. 제작 예시 — 센터원 업무 공유 프로그램 (대화 5번 + 폰 화면에서 실제로 눌러지는 결과물, 가짜 예시 데이터)
     - 마지막에 진짜 사이트 QR(`/center?room=오늘날짜`)로 다 같이 써 보기
- 마무리 — 오늘 가져갈 세 가지, Q&A

장마다 메시지 문장 + 2~3문장 설명 + 키워드 · 예시로 구성했습니다. 수치 · 사례는 각 장 하단과 강사 노트(`N`)에 출처가 있습니다. 화면이 작아 내용이 넘치는 장은 자동으로 살짝 줄여서 맞춥니다. 메뉴 이름 · 요금제별 제공 범위는 강의 직전 실제 화면으로 확인하세요.

## 사이트 주소
QR이 가리키는 주소는 `index.html` 맨 아래 `LIVE_BASE` 한 줄에서 바꿉니다 (지금: `https://ai-level-survey-weld.vercel.app`).
강의 전에 `/center?room=오늘날짜(예: 261013)`에 들어가 "예시 데이터로 채워 보기"를 눌러 두면 빈 화면 없이 시작합니다.
