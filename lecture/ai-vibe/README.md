# 생성형 AI 활용 업무 보조 바이브코딩 (3시간)

오프라인 발표용 덱입니다. `index.html`을 브라우저로 열고 `F`로 전체화면.
`fonts/` 폴더를 같은 위치에 두면 인터넷 없이도 글꼴이 그대로 나옵니다.

## 구성 (56장)
- 시작 전: 오프닝 영상 — 같은 폴더에 `opening.mp4`를 두면 덱 안에서 재생
- **1부 이론 (60분)**
  1. AI 활용 등급 진단 (진단 화면으로 전환하는 표지 포함)
  2. 2단계: 나만의 AI 생태계 구축하기 — 왜 써야 하나, 귀찮음 계산기, 생태계 지도, 환경 구축
  3. 바이브코딩이란
  4. 바이브코딩 제작 예시 — 태국 4박 5일 여행 프로그램 (대화 5번 + 실제 작동 결과물)
- **2부 보상지원 프로그램 개발해 보기 (120분, 조별)**
  1. 시연 (보상 카메라 어플 · AI 차량손해사정 프로그램 — 표지만, 시연은 폰 미러링/사이트)
  2. 조별 개발 아이디어 선정 및 뼈대 잡기
  3. AI를 통한 세부 기능 설계 (설계 요청문 복사 가능)
  4. HTML 결과물 도출 (첫 제작 요청문, 고도화, 막혔을 때, 제작 타이머)
  5. 조별 발표 (발표 틀, 3분 30초 발표 타이머)

## 단축키
| 키 | 기능 |
|---|---|
| `→` `←` `Space` | 다음 · 이전 |
| `F` | 전체화면 |
| `N` | 강사 노트 (진행 멘트 · 시간) |
| `O` | 전체 슬라이드 목록 |
| `T` | 강의 타이머 (180분) |
| `D` | 라이트 / 다크 |
